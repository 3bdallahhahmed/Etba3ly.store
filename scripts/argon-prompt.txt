## 2. Replace the Old Pricing Formula
The current system charges a flat 3.00 EGP per gram.
Replace this with:
Manufacturing Price = Setup Fee + (Estimated Filament Weight × Material Rate) + (Estimated Print Time in Hours × Hourly Printing Rate)

Use these default values:
- PLA: Selling Rate 1.80 EGP/g, Cost 0.65 EGP/g
- PLA+ / Rapid PLA: Selling Rate 2.00 EGP/g, Cost 0.75 EGP/g
- PETG: Selling Rate 2.10 EGP/g, Cost 0.70 EGP/g
- TPU: Selling Rate 2.70 EGP/g, Cost 0.95 EGP/g
- Carbon Fiber Filled: Selling Rate 3.50 EGP/g, Cost 1.35 EGP/g

Additional defaults:
- Setup fee: 25 EGP per order
- Printing hourly rate: 12 EGP/hour
- Minimum manufacturing subtotal for campus pickup: 75 EGP
- Minimum manufacturing subtotal for nationwide delivery: 150 EGP
- Standard packaging charge: 25 EGP for shipped orders
- Electricity cost: 0 EGP/hour by default, fully editable
- Maintenance and wear cost: 5 EGP/printing hour
- Printer ownership/depreciation allowance: 4.50 EGP/printing hour
- Failed-print material reserve: 8% of raw material cost

All these parameters MUST be editable in the admin dashboard and stored persistently in Supabase.
Do not hardcode financial parameters throughout the application.

## 3. Correct Price Calculation Logic
For each order:
1. Calculate total estimated filament weight, including supports, brim, and other consumed filament where supported by the slicing engine.
2. Calculate total estimated printer occupancy in hours.
3. Apply the selected material selling rate.
4. Add the setup fee only once per order.
5. Apply the minimum manufacturing subtotal according to fulfillment method.
6. Round the manufacturing subtotal UP to the nearest 5 EGP.
7. Add packaging and shipping separately.
8. Calculate the required deposit and remaining balance.

Formula:
rawSubtotal = setupFee + totalWeightG * materialSellingRate + totalPrintHours * printingHourlyRate;
minimum = deliveryMode === "pickup" ? pickupMinimum : shippingMinimum;
manufacturingSubtotal = Math.ceil(Math.max(rawSubtotal, minimum) / 5) * 5;
customerTotal = manufacturingSubtotal + packagingFee + shippingFee;

For multiple items, charge the setup fee only once.
Use accurate total printer occupancy from the slicing plan, rather than blindly summing times for parts that can be printed together.
